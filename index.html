How it stays unbiased

If you rolled a street and an avenue separately, you’d invent corners that don’t exist and over-weight short avenues. This dice does it the other way:

  • ✓
    Build the full list first. Every real intersection, using each avenue’s actual street range.
  • ✓
    Pick one corner from the whole list. Each corner gets exactly the same chance — 1 in —.
  • ✓
    No curation. Famous corners and completely ordinary ones are in the same pool.
Which avenues are in the dice?

    Diagonal Broadway and the irregular downtown grid below the numbered streets aren’t counted as avenue corners here — this is the numbered Manhattan grid only, so every result is a clean street-and-avenue corner you can navigate to.
